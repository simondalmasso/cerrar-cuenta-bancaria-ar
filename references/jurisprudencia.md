# Jurisprudencia: cuándo y cómo usarla

## Cuándo vale la pena

No buscar fallos para una baja normal. Activar jurisprudencia cuando el caso tenga una controversia real:
- rechazo repetido sin fundamento;
- cobro posterior discutido;
- incumplimiento de un acuerdo o reclamo resuelto;
- deber de información/trato;
- daño económico por la demora;
- discusión sobre cuenta corriente, descubierto o cierre.

## Orden de búsqueda

1. SAIJ oficial.
2. CSJN / Secretaría de Jurisprudencia.
3. Tribunales oficiales según jurisdicción.
4. MCP jurídicos de solo lectura como aceleradores.
5. Plataformas privadas solo para discovery.

El hallazgo MCP o privado **no es la cita final**. Abrir/verificar el origen oficial cuando sea posible.

## Términos útiles

- "cierre de cuenta bancaria"
- "cierre de cuenta corriente"
- "baja de producto bancario"
- "trato digno banco consumidor"
- "deber de información contrato bancario"
- "cobro posterior baja"
- "saldo deudor cuenta corriente"
- "intereses descubierto bancario"
- "incumplimiento acuerdo defensa del consumidor banco"

## Ficha mínima de un fallo

- tribunal;
- sala;
- fecha;
- carátula;
- identificador/expediente;
- cuestión decidida;
- hecho comparable con el caso actual;
- diferencia material;
- enlace oficial;
- estado: VERIFICADO / REFERENCIA / NO VERIFICADO.

## Regla de aplicación

No decir "este fallo obliga al banco" salvo que se haya analizado competencia, fuerza del precedente y hechos. Preferir:

> "Este antecedente muestra cómo un tribunal trató [problema] en [fecha/jurisdicción]. Puede ser útil como apoyo, pero no reemplaza la normativa BCRA específica ni garantiza el mismo resultado."
