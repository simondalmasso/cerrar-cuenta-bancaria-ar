# Caso sintético — loop de cierre

**Todo este ejemplo es ficticio.** No contiene datos, capturas, CUIT/DNI, números de cuenta, números de gestión ni conversaciones reales.

Objetivo: mostrar el handoff entre agentes y el flujo de evidencia sin usar información de usuarios.

Escenario:
- Banco Ejemplo S.A. (ficticio).
- Caja de ahorro ARS.
- Primer pedido de baja rechazado por un cargo residual.
- El usuario decide regularizarlo.
- Segundo intento vuelve a ser rechazado sin causa nueva.
- Se abre reclamo formal y se obtiene constancia de cierre.
- Se realiza control post-cierre.
