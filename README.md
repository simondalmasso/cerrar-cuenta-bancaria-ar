# cerrar-cuenta-bancaria-ar

Skill abierta y vendor-neutral para guiar a una persona humana en el cierre de una cuenta bancaria en Argentina, con evidencia, normativa vigente y escalamiento documentado.

**Principio central:** la IA guía, investiga y redacta; la persona opera sus canales bancarios. La skill no navega home banking, no mueve dinero, no envía solicitudes ni presenta reclamos por cuenta del usuario.

El paquete principal vive en `SKILL.md` y sigue el estándar abierto de Agent Skills.
